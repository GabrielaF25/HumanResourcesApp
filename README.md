Human Resources App is a web application designed to streamline HR processes, focusing on employee leave management. The project consists of a .NET 8 backend and a React frontend, providing a modern, responsive interface for HR staff and employees.

## Features

- **Employee Leave Management:** View, request, edit, and delete leave requests for employees.
- **Leave Overview:** Track total, consumed, and remaining leave days per employee.
- **User-Friendly Interface:** Responsive design using React and HTML5 UP templates.
- **RESTful API:** Backend built with .NET 8 for robust and scalable data handling.
- **Role-Based Access:** Secure endpoints for HR and employee actions.

## Technologies Used

- **Frontend:** React, JavaScript, HTML5 UP, CSS
- **Backend:** .NET 8, C#
- **Routing:** React Router
- **API Communication:** Fetch/Axios (frontend), REST (backend)
